| 项 | 内容 |

## 2. 范围边界（先划清，避免实现时越界）

### 2.1 L1 —— 主题包内可完成（`src/themes/atom-geek/`）

依据 `docs/THEMING.md` 的既有契约，主题目录**只能**包含 `manifest.json` + `light.css` + `dark.css`，内容只能是通过选择器
`html[data-theme='atom-geek'][data-mode='light|dark']` 定义的 **CSS 变量**。

可交付的视觉能力（全部由既有 40+ 必需 token 承载）：

- 页面/卡片/代码块/面板/吸顶栏的底色与层次
- 文字四级色阶、边框三级、强调色与副强调色
- 标签 / 分类 双语义通道配色
- 阴影与辉光（含 `--shadow-glow`、`--accent-glow-strong`）
- 网格底纹线 `--grid-line`、角落环境辉光 `--ambient-glow`（站点 `body::before/::after` 已消费这两个 token）
- 刻度尺刻度线 `--rule-tick` / `--rule-tick-strong`（站点 `.rule`、日志脊线已消费）
- 搜索命中高亮 `--highlight`、焦点环 `--focus-ring`
- 语义色 `--success` / `--warning`
- 强调色实心块上的文字色 `--on-accent`

### 2.2 L2 —— 需要站点级 CSS 增补（作用域限定 `html[data-theme='atom-geek']`）

下列视觉目标在 L1 内**不可达**，因为 `docs/THEMING.md` 明确禁止主题覆盖布局 token（`--radius*`、`--font-*`、`--max-width` 等），且禁止主题书写组件样式：

- 直角化（终端窗格感）、边框收窄为 1px 硬边
- 等宽字体角色重分配（把日期/序号/标签/状态/导航改用 `var(--font-mono)`）
- CRT 扫描线 / 噪点叠加层
- 窗口标题栏拟物（页头与代码块）
- 命令行式导航文案（`~/blog`、`~/tags` 等）与提示符前缀
- 首页 Hero、Telemetry 面板、404 空状态的终端化排版
- 快捷键提示条 / 命令面板（同时含 JS 行为，属站点级能力）

约束：L2 改动必须以 `html[data-theme='atom-geek']` 为作用域前缀，不得使用 `!important` 之外的强制手段影响其它主题，且不得改变 `atom-default` 的现有观感。

## 4. 视觉风格定义（极客风）

### 4.1 风格锚点（不可协商的 6 条）

1. **深色为默认基调**：暗色是主题的主形态，亮色为「磷光纸」变体。
2. **等宽字体承担「数据」**：日期、计数、序号、标签、状态、路径、快捷键一律等宽；正文与标题保持无衬线。
3. **霓虹强调色只用于「可交互/可操作」**：链接、主按钮、焦点环、当前激活项；正文不得大面积着色。
4. **硬边终端结构**：直角/近直角、1px 硬边框、无柔和投影，靠辉光而非投影制造层次。
5. **CRT 质感可感知但不喧宾夺主**：扫描线/噪点强度极低，且可关闭。
6. **真实数据**：所有终端式输出（Telemetry、计数、状态）必须来自站点真实数据，不得伪造。

### 4.3 L2 视觉规范（站点级，作用域 `html[data-theme='atom-geek']`）

| 维度 | 规范 |
|---|---|
| 圆角 | 直角化：面板/卡片/代码块 `border-radius: 0`；徽标类保留 ≤2px。**不得修改**全局 `--radius*` token |
| 描边 | 1px 硬边框，颜色取 `--border-color`；激活/悬浮态 `--border-glow`；焦点态 2px `--focus-ring` + 2px offset |
| 字号阶梯 | 展示标题 2.35rem/1.2 → 区块标题 1.6rem → 列表标题 1.2rem → 正文 1.02rem/1.75 → 摘要 0.88rem/1.7 → 等宽数据 0.76–0.80rem → 元信息 0.72–0.78rem（沿用既有 ≤768 / ≤480 断点的缩减节奏，不新增断点） |
| 字间距 | 等宽数据 `letter-spacing: .04–.10em` + `font-variant-numeric: tabular-nums`；标题保持 `-.02em` |
| 间距 | 8px 基数阶梯 4/8/12/16/20/24/32/48/64，与既有 padding 一致；不改变 `--max-width` / `--content-width` |
| 阴影 | 层次以辉光（`--shadow-glow` / `--accent-glow`）为主，投影仅保留 `--shadow-sm` 级 |
| 动效时长 | hover/状态切换 0.15–0.20s；进场 0.40–0.50s；刻度绘制 0.75s；扫描线循环 8s |
| 缓动 | `cubic-bezier(.22, 1, .36, 1)`（进场/刻度）、`ease`（状态切换） |
| CRT 质感 | 扫描线叠加 ≤3% 不透明度、噪点 ≤2%、仅覆在背景层不覆正文；`prefers-reduced-motion` 或高对比偏好下完全关闭 |
| 窗口标题栏拟物 | 页头与代码块：左侧 3 点状态点 + 标题文字（等宽），右侧为该区块实际操作（复制/模式切换） |
| 命令行导航 | 导航项以 `~/` 路径前缀呈现（内容层改动见 Q-05），当前页以高亮前缀标记 |
| 快捷键提示 | 页头或页脚提示条列出可用快捷键，等宽字体，弱化色 |

### 4.4 字体与布局 token 红线（主题包不得触碰）

`--font-display` / `--font-sans` / `--font-mono` / `--radius*` / `--max-width` / `--content-width` / `--header-height` / `--rule-height` / `--rule-major` / `--rule-minor` / `--log-gutter`
→ 极客风不得改写这些值，只能通过「用哪个字体变量」和「直角化」的局部作用域实现视觉差异。

## 11. 执行摘要（15 条）

1. 目标：为 Atom 博客新增第二套主题 `atom-geek`，主题包零配置生效，`atom-default` 原样保留。
2. 范围分层：L1 = 主题包内 40+ token 配色；L2 = 站点级 `html[data-theme='atom-geek']` 作用域增补（直角化、等宽角色、CRT、标题栏）。
3. 主题包只含 `manifest.json` + `light.css` + `dark.css`，禁止组件样式、`!important`、布局 token 覆盖。
4. 视觉主基调：暗色磷光绿（`#00e88f` on `#05070a`）+ 青色副通道（`#22d3ee`）；亮色为磷光纸变体。
5. 强调色只用于可交互元素，正文不着色；对比度正文 ≥4.5:1。
6. 硬边终端结构：直角、1px 边框、辉光代替投影、等宽字体承担全部「数据」。
7. 复用站点既有结构（刻度尺、日志列表脊线、Telemetry 面板、网格底纹、环境辉光），通过 token 换色，不重复造轮子。
8. 全部 10 条既有路由在两模式下零破版、零新增对比度违规、零新增破伤。
9. 既有功能（搜索、阅读进度、代码复制、图片放大、回到顶部、TOC、JSON-LD、OG、RSS）只做主题适配，不改行为。
10. 性能预算：LCP ≤2.5s、CLS ≤0.1、INP ≤200ms；主题包 ≤16KB，L2 CSS 增量 ≤8KB，主题引入 JS = 0。
11. 响应式沿用既有 5 个断点（1024/768/600/480/400），不新增断点；`prefers-reduced-motion` 下动效全关。
12. 不做：独立归档/作者/搜索结果页、真实评论区、多主题切换 UI、内容级文案大改、`about` 页相关未提交改动。
